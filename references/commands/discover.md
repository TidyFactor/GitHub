# Command: discover

Runtime entry point for Repository Discoverability Optimization (RDO), topics, and SEO.

## Dispatch steps

1. Load `../workflows/optimize-discoverability.md` — RDO execution workflow.
2. Load `../memory/rdo-matrix.md` — topic taxonomy and description formulas.
3. Audit and output recommended 8-12 topics, description string, and homepage URL.

## Do not

- Do not use overly generic topics (`javascript`, `web`, `code`).
- Do not exceed 120 characters in repository description.
