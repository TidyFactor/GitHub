# Workflow: design-social-preview

One outcome: a generated or specified Open Graph Social Preview card design (1280x640) for GitHub settings.

## Steps

1. Load `references/memory/repo-design-tokens.md`.
2. Extract project title, category pill, primary tagline, and ecosystem brand.
3. Formulate the visual specification:
   - Canvas: 1280 x 640 px, 2:1 aspect ratio.
   - Background: Dark Mode curated gradient (#0d1117 to #161b22).
   - Typography: Clean modern Sans-Serif.
   - Elements: Category badge, Title, Subtitle, Tech stack icons.
4. Output the design specification or prompt for image generation tools.

## Validation checklist

- [ ] Social preview specifications match 1280 x 640 px (2:1 aspect ratio)
- [ ] Safe-zone padding of 100px preserved for all edge elements
- [ ] Brand colors and typography align with TidyFactor design tokens
