# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security issues privately to `security@tidyfactor.com` or via GitHub Security Advisories.
Response SLA: Initial response within 48 hours.
